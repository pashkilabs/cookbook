description: Pick up the next roadmap task
---

Read `docs/roadmap.md` and identify the first unchecked task in the current
phase.

Before writing anything:
1. State which task you're taking and what "done" means for it.
2. Check `docs/decisions.md` — if it depends on an unresolved question, stop and
   say so instead of guessing.
3. Confirm the approach fits the rules in `CLAUDE.md`.

Then implement it, with tests. Finish with `pnpm check` and tick the box in
`docs/roadmap.md`.

One task. Don't run ahead into the next one.
